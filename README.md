## How to open the demo

**Do not open `http://localhost`.** That address only works on a computer that is already running a local server. If nothing is running, the browser shows “localhost refused to connect”.

Open the demo this way instead:

1. In this repository, open **`index.html`** in Chrome (double-click the file, or right-click → Open with → Chrome).
2. Click **Use** next to a demo account, then **Enter portal**.

Optional hosted copy after GitHub Pages is enabled:

https://tourshotelsresorts-create.github.io/THR/

## Optional: run a local server

Only use localhost after you start a server **on the same computer as the browser**:

```bash
python3 -m http.server 4173
```

Then visit http://127.0.0.1:4173
