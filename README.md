# THR India

Demo portal for Tours, Hotels & Resorts in India.

## Demo login details

Open `index.html` in a browser (or serve the folder) and sign in with any of these accounts:

| Role | Email | Password |
| --- | --- | --- |
| Admin | `admin@thrindia.demo` | `Demo@THR2026` |
| Travel Agent | `agent@thrindia.demo` | `Agent@THR2026` |
| Guest | `guest@thrindia.demo` | `Guest@THR2026` |

These credentials are for local demo use only. They are shown on the login screen as well.

## Run locally

```bash
python3 -m http.server 4173
```

Then visit http://localhost:4173
